# README for Docs and Specs

The canonical home for all documentation and specifications is the [Maglev Wiki](https://github.com/OneBusAway/maglev/wiki). The docs hosted here are provided as historical artifacts, but engineers and AI tools referencing these specs *must* consult the Wiki to ensure that they have correct, up-to-date information.

Write new specs on the wiki, not in this folder. The design specs that used to live here are now wiki-only:

- [PostgreSQL-Support](https://github.com/OneBusAway/maglev/wiki/PostgreSQL-Support) (horizontal scalability and PostgreSQL)
- [Multi-Agency-Static-Feeds-Stop-Consolidation](https://github.com/OneBusAway/maglev/wiki/Multi-Agency-Static-Feeds-Stop-Consolidation) (multi-feed static GTFS loading)
